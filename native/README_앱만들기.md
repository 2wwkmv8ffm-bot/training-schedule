# ZONE 안드로이드 앱 만들기 (화면 꺼져도 GPS 기록)

웹 앱을 그대로 감싸서 **안드로이드 앱**으로 만들어요. 앱에서는 **화면이 꺼져도·다른 앱을 써도 GPS가 계속 기록**돼요.
(아이폰 앱은 맥(Mac) 컴퓨터와 Xcode가 있어야 만들 수 있어서, 윈도우에서는 안드로이드부터 해요.)

## 1. 한 번만 설치 (무료)
1. **Node.js LTS** — https://nodejs.org → LTS 버전 설치
2. **Android Studio** — https://developer.android.com/studio → 설치 후 처음 실행해서 기본 SDK 설치까지 완료

## 2. 앱 프로젝트 만들기 (이 `native` 폴더에서)
```
npm install
npm run setup
```
- 웹 파일 복사 → 안드로이드 프로젝트 생성 → 위치 권한 추가 → 동기화까지 한 번에 해요.

## 3. 휴대폰에 설치
```
npm run open
```
- Android Studio가 열리면, 휴대폰을 USB로 연결하고(휴대폰: 설정 → 휴대전화 정보 → 빌드번호 7번 탭 → 개발자 옵션 → USB 디버깅 켜기) **▶ Run** 을 누르면 설치돼요.
- 설치 파일(APK)이 필요하면: Android Studio 메뉴 **Build → Build App Bundle(s)/APK(s) → Build APK(s)**

## 4. 웹을 고친 뒤 앱에 반영
```
npm run sync
```
그다음 Android Studio에서 다시 ▶ Run.

## 앱에서 처음 기록할 때
- 위치 권한을 물으면 **"앱 사용 중에만 허용"** 이상을 고르고, 가능하면 설정에서 **"항상 허용"**으로 바꿔 주세요.
- 기록 중에는 알림창에 **"ZONE 기록 중"**이 떠 있어요. 이게 있어야 화면이 꺼져도 측정이 계속돼요.
- 배터리 최적화가 심한 휴대폰(일부 삼성·샤오미)은 설정 → 배터리 → ZONE을 **"제한 없음"**으로 해 주세요.

## 참고
- 플레이스토어에 올리려면 구글 개발자 계정(1회 25달러)이 필요해요. 가족·친구끼리는 APK 파일로 나눠 설치해도 돼요.
- 앱은 인터넷이 있어야 해요 (Supabase 저장, 지도).

## 🍎 아이폰 앱 만들기 (맥에서)
맥(Mac) + Xcode가 필요해요. 이 `native` 폴더를 맥으로 옮긴 뒤 터미널에서:
```
npm install
npm run setup:ios
npm run open:ios
```
- `setup:ios`가 아이폰 **권한 설명 문구(한국어)**를 자동으로 넣어 줘요 (`patch-ios.js`).
  - 위치: "운동을 기록하는 동안 달린 거리·페이스·경로를 재기 위해…" (앱 사용 중 + 항상)
  - 카메라·사진: 커뮤니티 글·프로필 사진 올리기
  - 블루투스: 심박계 연결
  - 백그라운드 위치(기록 중 화면이 꺼져도 측정) · 앱 기본 언어 한국어
- 웹을 고친 뒤 아이폰 앱에 반영: `npm run sync:ios` → Xcode에서 ▶ Run.
- 애플 심사 메모: 위치는 '운동 기록 중에만' 쓰고, 처음 기록할 때 앱 안에서 먼저 안내·동의를 받아요. 커뮤니티는 처음 들어갈 때 이용 규칙 동의 + 신고·차단 기능이 있어요.
