**출시(아이폰·안드로이드 같은 날) 뒤에** 진행해요. 사장님이 "업데이트해서 올리자"라고 하면 이 목록부터 다시 알려 드려요.

## 1. 건강 앱 연결 (가장 중요)
- 아이폰: **애플 건강**에서 운동 기록 읽기
- 안드로이드: **헬스 커넥트(삼성 헬스 포함)** 에서 운동 기록 읽기
- 가민·코로스·애플워치 기록이 건강 앱을 거쳐 무료로, 인원 제한 없이 들어와요.
- 들어온 기록은 같은 날 같은 종목 계획을 자동으로 '완료'로 바꿔요 (이미 만들어 둔 기능).
- 심사 대비: 개인정보 처리방침에 '건강 데이터는 운동 기록 가져오기에만 쓰고 광고·판매에 쓰지 않아요' 추가.

## 2. 알림
- "오늘 훈련 있어요" 아침 알림 (시간은 사용자가 고르기)
- 커뮤니티 좋아요·댓글 알림

## 3. 앱 이름 다듬기
- 예: "ZONE - 수영·자전거·러닝 훈련" (지금 이름은 쉼표가 어색해요)

## 4. 앱 만들기 설정 정리 (맥에서)
- patch-ios.js: 암호화 사용 안 함(ITSAppUsesNonExemptEncryption) 자동 추가, 최소 iOS 15, 장면 설정(SceneDelegate)
- 아이폰 전용으로 할지 (아이패드 지원 끄기) 결정
